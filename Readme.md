## initial set up
### Both
1. Check `CMAkeVariables.txt.dummy`.
2. Set up file as described by comments.

### Windows
1. `ctr + shft + p` to open command palette and search for `CMake: Select Kit`
2. Choose Clang
3. run `CMake: Configure` from command palette.
4. Select the appropiate run command in debug tab `ctrl + shift + d` 
5. `f5`
